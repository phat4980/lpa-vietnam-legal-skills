# Vietnamese Legal Research

## Workflow

### 1. Frame the issue

Extract:

- jurisdiction
- transaction type
- industry
- parties
- relevant date
- legal question
- business objective

### 2. Build search terms

Use Vietnamese legal terminology, synonyms, and the exact transaction concept.

Examples:

- mua bán hàng hóa
- phạt vi phạm
- bồi thường thiệt hại
- chậm thanh toán
- giao nhận
- chuyển rủi ro
- khiếu nại chất lượng
- hóa đơn
- chấm dứt hợp đồng

### 3. Retrieve

Prefer authoritative sources first.

Use secondary datasets only to discover relevant documents or provisions.

### 4. Verify

For each material proposition:

1. Locate the exact provision.
2. Identify document number and title.
3. Check status.
4. Check effective date.
5. Check amendments/repeal/replacement.
6. Check transitional provisions.
7. Confirm applicability to the transaction.

### 5. Answer

Use:

```text
KẾT LUẬN

CĂN CỨ PHÁP LÝ

PHÂN TÍCH

ÁP DỤNG VÀO TRƯỜNG HỢP

RỦI RO / NGOẠI LỆ

NGUỒN
```

## Evidence policy

If verification is unavailable, explicitly say:

`[CẦN XÁC MINH]`

Never create a plausible-looking citation.

## Temporal rule

If the contract was signed in the past, determine the law applicable to the relevant event instead of automatically applying today's law.

## Conflicting sources

When sources disagree:

1. Prefer higher-authority source.
2. Prefer later valid amendment where applicable.
3. Check consolidated text.
4. Check transitional provisions.
5. Explain the conflict rather than hiding it.
