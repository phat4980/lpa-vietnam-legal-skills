# Contract Quality Gate

A contract is not final until:

- [ ] parties verified
- [ ] signing authority addressed
- [ ] scope clear
- [ ] goods/services clear
- [ ] quantity/unit clear
- [ ] price/VAT clear
- [ ] order mechanism clear
- [ ] delivery clear
- [ ] acceptance clear
- [ ] quality criteria clear
- [ ] complaint process clear
- [ ] payment clear
- [ ] credit term approved
- [ ] penalty reviewed
- [ ] damages reviewed
- [ ] liability exposure reviewed
- [ ] termination reviewed
- [ ] force majeure reviewed
- [ ] dispute mechanism clear
- [ ] governing law clear
- [ ] appendices consistent
- [ ] no contradictory terms
- [ ] no fake citations
- [ ] no unresolved placeholders
- [ ] high-risk items escalated
